# Project 1: The To-Do List

**Batch:** 2026

## Overview

A modular Python command-line application that allows users to add tasks to a list and view them. This project demonstrates foundational data management, utilizing lists and dictionaries to build an in-memory database, which is serialized to a JSON file for persistent storage.

## Execution

Ensure Python 3.9+ is installed. Run the application via your terminal:
`python todo_app.py`
